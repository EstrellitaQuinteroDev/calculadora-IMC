# Calculadora de Índice de Masa Corporal (IMC) - React

Esta es una aplicación interactiva desarrollada con **React.js** como parte de la evidencia para el programa de formación de Análisis y Desarrollo de Software (ADSO).

## 🚀 Funcionalidades

- Captura de peso en kilogramos y estatura en centímetros.
- Cálculo automático del IMC basado en la fórmula estándar.
- Clasificación dinámica (Bajo peso, Normal, Sobrepeso, Obesidad) con cambios de color en la interfaz.

## 🛠️ Tecnologías utilizadas

- **React.js** (Hooks: useState)
- **JavaScript** (Lógica de cálculo)
- **CSS** (Diseño responsivo y dinámico)

## 📦 Instalación y Ejecución

Para ejecutar este proyecto localmente, sigue estos pasos:

1. Clona el repositorio.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta `npm install` para instalar las dependencias.
4. Ejecuta `npm start` para iniciar la aplicación en el navegador.
